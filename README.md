# Исследование трудоустройства выпускников вузов и СПО (2024 г.)

## Описание исследования
Данная работа посвящена анализу востребованности выпускников российских образовательных организаций на рынке труда. В основе исследования лежат данные Мониторинга трудоустройства выпускников Роструда.

Основные задачи исследования:
1. Оценка доли выпускников, работающих в соответствии с полученной квалификацией.
2. Анализ феномена «избыточного образования» (overeducation) в массовых секторах экономики, таких как общественное питание и логистика.
3. Сравнение уровня номинальных заработных плат специалистов, занятых по профилю, и тех, кто вынужден работать на позициях, не требующих высшего образования.

Ключевой вывод: работа по специальности обеспечивает среднюю премию к заработной плате в размере 13%, при этом наибольшая концентрация кадров с избыточной квалификацией наблюдается в сервисных индустриях.

## Инструкция по запуску
Для генерации графиков и отчета необходимо выполнить следующие команды:
```sh
git lfs pull
```
